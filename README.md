# Screen Time Blocker (Android App)

Полноценное приложение для контроля экранного времени и блокировки приложений/сайтов.

## Особенности дизайна и функционала:
- **Liquid Glass (Glassmorphism)**: темно-серые полупрозрачные карточки с тонкими светлыми границами на абсолютном черном фоне (`#000000`).
- **Строгая типографика**: единый аккуратный размер шрифта для всех элементов (тексты, счетчики `- 100 +`, кнопки).
- **Изолированное хранилище Room**: настройки, списки приложений и сайтов для **Мягкого** и **Жесткого** режимов хранятся раздельно.
- **Интерактивные счетчики**: можно нажимать `+` / `–` или нажать на само число и ввести значение с клавиатуры.
- **Вспомогательные экраны**:
  - Выбор приложений с лимитами в минутах.
  - Блокировка сайтов с добавлением URL и удалением через красную корзину.
  - Установка и ввод пароля.
  - Мотивация (текст + прикрепление фото).
  - Дыхательная практика.
- **Валидация жесткого режима**: нельзя одновременно отключить дни и пароль (нужна хотя бы одна мера восстановления).

## Как преобразовать проект в APK:

1. Откройте папку `блокировка` в **Android Studio** (`File -> Open...`).
2. Дождитесь автоматической синхронизации Gradle (Gradle Sync).
3. В верхнем меню выберите:
   `Build` -> `Build Bundle(s) / APK(s)` -> `Build APK(s)`.
4. После окончания сборки в правом нижнем углу появится уведомление `APK(s) generated successfully` с кнопкой **locate**.
5. Полученный файл `app-debug.apk` скиньте на свой телефон (через Telegram или USB-кабель) и установите!
